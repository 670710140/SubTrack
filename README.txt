SubWise connected website prototype

Open index.html to start at the Dashboard. The bottom navigation links connect Dashboard, Calendar Reminders, Expense Analytics, and Cancel Guide. Click the profile avatar in the top-right corner on any page to open Profile & Settings.

Keep all HTML files in the same folder. This is a front-end prototype; it does not have a backend/database, and some buttons only demonstrate UI behavior. It uses online fonts/icons and Tailwind CDN, so an internet connection is needed for those assets.
